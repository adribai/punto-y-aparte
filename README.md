# Punto y Aparte

## Descripción

Punto y Aparte es una web de un foro para gente a la que le gusta leer. En la página de inicio se pueden ver los libros que están más de moda en España, con algunas reseñas y opiniones de los usuarios.

Está pensada para cualquier persona que lea o que quiera empezar a leer y no sepa qué libro elegir. Muchas veces las recomendaciones están en sitios distintos (redes sociales, tiendas...) y aquí la idea es tenerlo todo en el mismo sitio y poder hablar con otros lectores.

## Estructura del Prototipo

Hay un menú arriba en todas las páginas para moverse entre ellas.

* **index.html:** Página de inicio con los libros populares, sus reseñas y un panel con opiniones de los usuarios.
* **profile.html:** Perfil de un usuario con sus datos, el libro que está leyendo, sus reseñas y sus libros favoritos.
* **contact.html:** Formulario para unirse al foro y colaborar.
* **success.html:** Página que sale al enviar el formulario diciendo que la cuenta se ha creado (es simulada, no se envía nada).

## Tecnologías Utilizadas

* HTML5
* CSS3

## Enfoque Técnico

* Diseño Mobile First: primero hice los estilos para móvil y después una media query para pantallas más grandes.
* Uso de selectores básicos (etiqueta, clase e id) y combinados (por ejemplo `.navbar a` o `.book h3`).
* Uso de diferentes valores de Display (`flex`, `grid`, `inline-block`) y Position (`sticky`, `relative`, `absolute`).
